# Matthew Klanfer · Game Portfolio

Live site: **https://salvinorin95.github.io**

Selected in-engine moments from two Unity games in development:

- **The Sea Beyond Farewell**: a nautical adventure on a Mediterranean coast, featuring the submarine PortMatt.
- **Picker Tripper**: psychedelic survival action on a tiny elliptical planet, starring Pigger the hippie wild boar.

I design the games, build the characters in Blender, playtest every build, and direct the AI coding agents (Claude Code, Codex and Grok) that write most of the code.

This repository holds only the static portfolio site: plain HTML/CSS, images and short silent video clips. The game source code is private.
